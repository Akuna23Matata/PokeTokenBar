# Simplified Chinese localization review images

Sample-data renders of the production PokeTokenBar SwiftUI views, for review of the Simplified Chinese localization contribution.

- Before: upstream commit `38e3e5532846d407ae1a80fe15c4e49a0c263d65`, English.
- After: Simplified Chinese localization on that base.
- Both use the same isolated sample save, light appearance and viewport dimensions.
- These are local AppKit/SwiftUI test renders, not captures of an installed app. The test bundle version appears in the settings footer. AppKit's offscreen segmented controls can omit inactive labels.
- No user account, usage history, credentials or personal save data appears in these images.
- This separate evidence branch is for PR documentation only. None of these images are included in the contribution branch or app bundle.

PokeTokenBar is an unofficial, non-commercial fan project. Pokémon and associated artwork are owned by Nintendo, Game Freak, Creatures Inc. and The Pokémon Company. Sprites shown within the app UI were fetched at runtime from the project's existing public PokéAPI source; these images document the UI rather than providing standalone assets.
